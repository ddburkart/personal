# Adventures of Linh & David — Vol. 1 🌙

A five-page interactive comic, with swipe navigation, mobile panel-by-panel reading, and a little surprise at the end.

## Publish with GitHub Pages

1. Upload `index.html` and the five `.jpg` files to the root of this repository (not the ZIP).
2. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then `main` and `/ (root)`. Save.
3. Open `https://ddburkart.github.io/personal/`.

No build tools or server required.
